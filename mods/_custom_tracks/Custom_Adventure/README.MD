
# CUSTOM TRACK ADVENTURE🌍


# THIS MOD ALLOWS YOU TO LOAD 28 CUSTOM TRACKS IN ADVENTURE MODE AND ADD SOME CUSTOMIZATION TO THEM

TRACK DISTRIBUTION:
- 6 TRACKS PER HUB, 28 IN TOTAL
- 4 IN NORMAL WARP PADS
- 1 IN EACH BOSS GARAGE
- 1 IN EACH CRYSTAL CHALLENGE WARP PADS
- +1 IN SLIDE COLISEUM
- +1 IN TURBO TRACK!


PD: YOU CAN PLAY WITH EVERY CHARACTER IN THIS CUSTOM ADVENTURE MODE! AND EVEN CHANGE THE ENGINE OF THEM


WARNING!:
- 🟣YOU NEED TO COMPLETE PURPLE TOKEN WARP PADS TO BEING ABLE TO CONTINUE!🟣

 ⏰THE SAME THING APPLIES FOR TURBO TRACK/SLIDE COLISEUM⏰


# CUSTOMIZATION
THERE ARE SOME MODIFIERS IN "adventure_settings.c" THAT CAN BE MODIFIED BY THE USER, E.G:

 - 🎵TRACK ID (FOR TRACK MUSIC)🎵
 - 🏁NUMBER OF LAPS PER TRACK🏁
 - ✨IF THE TRACK SHOULD SHOW STARS IN THE SKY✨
 - 🚩GAME LANGUAGE LIKE CTR PAL VERSION🚩
 - ⚙️QUADBLOCK MODIFIERS LIKE WEAPONS, LAP COUNT, HAZARDS, AND MORE!⚙️
