
# CUSTOM HUB ADVENTURE🌍


# THIS MOD ALLOWS YOU TO MAKE A CUSTOM HUB AND LOAD 28 CUSTOM TRACKS IN ADVENTURE MODE WITH SOME CUSTOMIZATION TO THEM

DISTRIBUTION:
- 5 TRACKS PER ZONE, 27 IN TOTAL
- 4 RACE TRACKS IN EACH ZONE (EXCEPT ZONE 2 WHICH ONLY HAVE 1)
- 1 BOSS IN EACH ZONE
- 1 DOOR PER ZONE (EXCEPT ZONE 1)


PD: YOU CAN PLAY WITH EVERY CHARACTER IN THIS CUSTOM ADVENTURE MODE! AND CHANGE THE ENGINE STATS PRESSING START BUTTON


WARNING!:
- 🟣THIS MOD REQUIRES TO CONFIGURE ADVENTURE_SETTINGS.C A LOT!🟣

REQUIREMENTS:
- QUADBLOCK IDS FROM ALL WARP PAD QUADBLOCKS (YOU CAN FIND THEM ON THE TRACK EDITOR OPENING THE .LEV FILES ON THE RENDERER)
- 1 QUADBLOCK WITH RED TEXTURE APPLIED
- 1 QUADBLOCK WITH INVISIBLE TEXTURE APPLIED
- 5 DOORS WITH COLLISION FLAG ENABLED, MUST BE WALLS
- 8 DIFFERENT SPAWN POINTS TO TELEPORT THE DRIVER WHEN 1 ZONE IS COMPLETED (SPAWNS 0 - 7)

# CUSTOMIZATION
THERE ARE SOME MODIFIERS IN "adventure_settings.c" THAT CAN BE MODIFIED BY THE USER, E.G:

 - 🎵TRACK ID (FOR TRACK MUSIC)🎵
 - 🏁NUMBER OF LAPS PER TRACK🏁
 - 🏁RACEFLAG COLOR🏁
 - 🏆PRIZE COLOR (RELIC)🏆
 - ✨IF THE TRACK SHOULD SHOW STARS IN THE SKY✨
 - 🚩GAME LANGUAGE LIKE CTR PAL VERSION🚩
 - ⚙️QUADBLOCK MODIFIERS LIKE WEAPONS, LAP COUNT, HAZARDS, AND MORE!⚙️
