THIS IS AN ALTERNATIVE VERSION FOR PS1_TRACKROM (COMPATIBLE WITH GHOSTS), IT STORES THE CUSTOM TRACK INSIDE CRASH COVE 1P, ALLOWS YOU TO TOGGLE WEATHER OR PLAY WITH BLUE FIRE, FIXES WALL SPLAT BUG WITH CUSTOM CHARACTERS, FIXES SAFFI FIRE AND INCLUDES RESERVES METER MOD, MOST OF CUSTOM TRIGGERS NEEDS TO BE ENABLED MANUALLY IN "mainmenu_stuff.c"
