# 🏆CUSTOM TRACK CUP MOD🏆

THIS MOD ALLOWS YOU TO COMPILE 4 CUSTOM TRACKS IN THE SAME ROM AND PLAY THEM IN A CUP!


# 🧱QUADBLOCK MODIFIERS🧱
THIS MOD ALLOWS YOU TO SET A CUSTOM EFFECT WITH DESIRED QUADBLOCKS E.G:

- 📦WEAPON TRIGGER (ITEM CRATES IN THE FLOOR)
- 🐢TURTLE JUMP
- ⌚CLOCK EFFECT
- 🏁LAP INCREMENT
- AND MORE!

HAZARDS:
- EATEN🍽️
- SQUASHED🦶
- BURNED🔥
- SPIN↪️
- BLASTED🚀

YOU CAN CHANGE ALL OF THEM AS YOU WISH IN "tracks_settings.c"

# 🛣️TRACK MODIFIERS🛣️
YOU CAN MODIFY THE TRACK ID TO CHANGE THE MUSIC OF THE TRACKS OR CHANGE THE GAMEMODE AND LAP NUMBER PER TRACK!

YOU CAN CHANGE ALL OF THEM AS YOU WISH IN "tracks_settings.c"
